📋 Installation Guide (Developer Mode)
The extension is pending Chrome Web Store review. In the meantime, install it in Developer Mode — it's the same extension, just loaded locally. Takes about 60 seconds.
1
Download the extension zip
Click the Download button above. Save snapcaption-ai-extension.zip anywhere on your computer.
2
Unzip the file
Extract the zip. You'll get a folder named snapcaption-ai-extension containing manifest.json and other files.
3
Open Chrome Extensions
In Chrome, go to chrome://extensions (or Menu → More tools → Extensions).
4
Enable Developer Mode
Toggle "Developer mode" in the top-right corner of the Extensions page.
5
Load the extension folder
Click "Load unpacked" → select the extracted snapcaption-ai-extension folder. The SnapCaption AI icon appears in your toolbar.
6
Pin it to your toolbar
Click the puzzle-piece icon in Chrome → pin SnapCaption AI so it's always one click away.
